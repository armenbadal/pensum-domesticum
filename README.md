# Տնային աշխատանքի տետր

**Pensum Domesticum · տարբերակ 0.1.0**

Ծրագիրը նախատեսված է տնային աշխատանքների տետրեր կազմելու և դրանք սովորողներին լրացնելու տալու համար։ Աշխատանքը պահպանվում է `.pdw` ֆայլով․ դրանում պահվում են տետրի տվյալներն ու կցված նկարները։

## Դասատուի ռեժիմ

1. «Կարգավորումներ»-ում ընտրեք «Դասատու» ռեժիմը և լրացրեք դասատուի անունն ու էլ․ փոստը։
2. «Տետր» մենյուից ընտրեք «Ստեղծել»՝ նոր տետր սկսելու կամ «Բացել»՝ առկա `.pdw` տետրն ընտրելու համար։
3. Նշեք տետրի թեման, անհրաժեշտության դեպքում լրացրեք նկարագրությունը՝ բացատրություններով, պահանջներով կամ տեսական նյութով, ապա ավելացրեք առաջադրանքներ։ Յուրաքանչյուր պայմանի մեջ կարող եք ավելացնել տեքստ, նկար կամ վանդակավոր դաշտ։
4. Ընտրեք «Տետր → Պահպանել»։ Դասատուի անունն ու էլ․ փոստը, ինչպես նաև վերջին պահպանման ամսաթիվը ներառվում են տետրում։

Դասատուն կարող է բացել սովորողի լրացրած տետրը․ պայմաններն ու լուծումները մնում են միայն դիտման համար, իսկ անհրաժեշտության դեպքում յուրաքանչյուր լուծման տակ կարելի է ավելացնել մեկնաբանություն։ Տետրի ներքևում կարելի է նշել 1–20 գնահատականը և պահպանել գրախոսված տետրը։

## Սովորողի ռեժիմ

1. «Կարգավորումներ»-ում ընտրեք «Սովորող» ռեժիմը և լրացրեք ձեր անունն ու էլ․ փոստը։ Սովորողի տվյալները պահվում են այս սարքի կարգավորումներում՝ դասատուի տվյալներից առանձին։
2. «Տետր → Բացել»-ով բացեք դասատուից ստացած `.pdw` ֆայլը։
3. Առաջադրանքների պայմանները դիտման համար են։ Լուծման բաժնում կարող եք ավելացնել տեքստ, նկար կամ վանդակավոր դաշտ։
4. Լուծումը պահպանեք «Տետր → Պահպանել»-ով։ Պատասխանի տետրում պահպանվում են դասատուի և սովորողի անուններն ու էլ․ փոստերը։ Ֆայլի անվանը սովորաբար ավելացվում է `-response`։

Պահպանված լուծումը դասատուն կարող է բացել գրախոսման համար։ Գրախոսված տետրը սովորողը կարող է բացել և դիտել մեկնաբանություններն ու գնահատականը։

## Վանդակավոր դաշտ

Դաշտը սկզբում ունի 10 տող և 20 սյուն։ Տողերն ու սյուները կարող եք ավելացնել կամ հեռացնել՝ թողնելով առնվազն մեկ տող և մեկ սյուն։ Վանդակներում թույլատրվում են թվանշաններ և մաթեմատիկական նշաններ։ Վանդակներ ընտրելով՝ կարող եք հաստացնել ներքևի կամ ձախ եզրագծերը, իսկ «Մաքրել» կոճակով՝ հեռացնել ընտրված տիրույթի հաստ եզրագծերը։

## Պահպանում և սահմանափակումներ

- Տետրը ավտոմատ չի պահպանվում։ Նոր տետր ստեղծելիս, այլ տետր բացելիս կամ ծրագրից դուրս գալիս՝ չպահպանված փոփոխությունների դեպքում ծրագիրը հաստատում է խնդրում։
- `.pdw` ֆայլը բացեք այս ծրագրով․ այն պարունակում է տետրի տվյալներն ու նկարները։
- «Ուղարկել» գործողությամբ էլ․ փոստով փոխանցումը դեռ հասանելի չէ։
