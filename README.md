# Pensum Domesticum

**Pensum Domesticum**-ը տնային աշխատանքների տետրեր կազմելու, լրացնելու և ստուգելու desktop հավելված է։ Այն կառուցված է Tauri 2-ի, Rust-ի և վանիլային HTML/CSS/JavaScript-ի հիման վրա։

## Հնարավորություններ

- Դասատուի և սովորողի առանձին աշխատանքային ռեժիմներ՝ պահպանվող պրոֆիլի տվյալներով, այդ թվում սովորողի դասարանը։
- Ռեժիմը որոշվում է թվային ստորագրությամբ դասատուի `.pdcert` հավաստագրով․ հավաստագիր չլինելու դեպքում հավելվածն աշխատում է սովորողի ռեժիմով։
- Դասատուի հավաստագիրը կարելի է ներմուծել կամ փոխարինել **Տետր → Հավաստագիր…** կետով՝ երկու ռեժիմներում էլ։
- Տետրերի ստեղծում, բացում և պահպանում `.pdw` ֆայլերով։
- Ծրագիրը գործարկվում է դատարկ պատուհանով․ նոր տետրը ստեղծվում է **Տետր → Ստեղծել**-ով, իսկ եղածը բացվում՝ **Տետր → Բացել**-ով։
- Դատարկ պատուհանում աշխատանքը սկսվում է վերին պատկերակային toolbar-ից կամ native մենյուից․ **Ստեղծել**, **Բացել**, **Պահպանել** և **Պահպանել որպես…**։
- Թեմայի, նկարագրության և առաջադրանքների կառավարում։
- Տեքստի, պատկերների և վանդակավոր դաշտերի ավելացում։
- Սովորողի կողմից առաջադրանքի վանդակավոր դաշտը լուծման մեջ պատճենելը և խմբագրելը։
- Սովորողի լուծումների դիտում, առաջադրանքների մեկնաբանում և հինգ ժպտիկից մեկով գնահատում։
- Սովորողի ուղարկած տետրը բացելիս դասատուն տեսնում է ուղարկողի անունն ու դասարանը։
- Ստուգված տետրերի դիտում սովորողի կողմից՝ միայն read-only ռեժիմում։
- Windows-ի տեղադրված տարբերակի թարմացումների ստուգում և օգտվողի հաստատմամբ տեղադրում։

## Դերերի որոշումը և փորձնական հավաստագիրը

Հավելվածը չի առաջարկում ռեժիմի ձեռքով ընտրություն։ Դասատուի ռեժիմը հաստատվում է միայն Rust backend-ում վավերացված Ed25519 հավաստագրով, որը պահվում է հավելվածի config պանակում՝ `teacher.pdcert` անունով։ Հավաստագրի բացակայության, անվավեր լինելու կամ ստուգման սխալի դեպքում հավելվածն անցնում է սովորողի ռեժիմի։

Մշակման ժամանակ ռեժիմը փորձարկելու համար կարելի է սահմանել `PENSUM_DEV_ROLE` միջավայրի փոփոխականը՝ `teacher` կամ `student` արժեքով։ Այն գործում է միայն debug build-ում․ փոփոխականի բացակայության, դատարկ կամ անվավեր արժեքի դեպքում ընտրվում է սովորողի ռեժիմը, իսկ release build-երում դերերը շարունակում են որոշվել հավաստագրով։

Ներկա կոդում production հանրային բանալին դեռ placeholder է, ուստի հավաստագրի ներմուծումը մինչև maintainer-ի bootstrap գործողությունը չի ընդունվի։ Փորձնական բանալու և `.pdcert`-ի ստեղծման, հանրային բանալին կոդում տեղադրելու ու հավաստագիրը փորձարկող դասատուներին տրամադրելու հրահանգը՝ [docs/certificate-bootstrap.md](./docs/certificate-bootstrap.md)։

Փորձարկման ժամանակ ներմուծված հավաստագիրը կարելի է ջնջել հրամանային տողից՝

```sh
python3 tools/reset_teacher_certificate.py
```

Սկրիպտը ջնջում է հավելվածի config պանակի `teacher.pdcert`-ը․ հավելվածը վերագործարկելուց հետո այն կաշխատի սովորողի ռեժիմով։ Մանրամասները՝ [docs/certificate-bootstrap.md](./docs/certificate-bootstrap.md)։

## Օգտագործողի ձեռնարկներ

- [Դասատուի ձեռնարկ](./docs/teacher-guide.md)՝ հավաստագրի ներմուծում, տետրի կազմում, սովորողի լուծման ստացում, գնահատում։
- [Սովորողի ձեռնարկ](./docs/student-guide.md)՝ ուսուցչի տետրի բացում, լուծում, պահպանում և ուղարկում։

## Տեխնոլոգիաներ

- **Frontend:** HTML, CSS, JavaScript՝ առանց frontend framework-ի կամ package manager-ի։
- **Backend:** Rust՝ Tauri 2-ի միջոցով։
- **Տետրերի ձևաչափ:** `.pdw` ZIP արխիվ՝ `workbook.json` տվյալներով և ներկառուցված պատկերներով։

## Նախագծի կառուցվածք

```text
src/                         Frontend-ի HTML, CSS, JavaScript և պատկերակներ
src/components/math-grid/    Վանդակավոր դաշտի բաղադրիչ
src-tauri/                   Tauri կարգավորումներ և Rust backend
tools/release.py             Ռելիզի պատրաստման և հրապարակման սկրիպտ
tools/pilot_certificate.py   Maintainer-ի offline հավաստագրի bootstrap գործիք
tools/reset_teacher_certificate.py Փորձնական հավաստագիրը ջնջող գործիք
workbook.schema.json         Պահպանվող տետրի տվյալների JSON Schema
```

## Մշակման միջավայր

Պահանջվում են Rust toolchain-ը և Tauri 2-ի համակարգային build prerequisites-ը։ Tauri-ի պահանջներին համապատասխան նախապատրաստեք ձեր օպերացիոն համակարգը՝ [Tauri-ի prerequisites ուղեցույցով](https://v2.tauri.app/start/prerequisites/)։

Տեղադրեք Tauri CLI-ն՝

```sh
cargo install tauri-cli --version "^2.0.0" --locked
```

Մշակման ռեժիմով գործարկելու համար՝

```sh
cd src-tauri
cargo tauri dev
```

Մշակման ժամանակ դասատուի կամ սովորողի ռեժիմը ընտրելու համար նույն պանակում գործարկեք՝

```powershell
$env:PENSUM_DEV_ROLE = 'teacher' # կամ 'student'
cargo tauri dev
```

Եթե փոփոխականը հեռացվի (`Remove-Item Env:PENSUM_DEV_ROLE`) կամ դատարկ լինի, մշակման build-ը կաշխատի սովորողի ռեժիմով։

Desktop հավելվածը կառուցելու համար՝

```sh
cd src-tauri
cargo tauri build
```

## Ստուգումներ

Հրամանները գործարկեք նախագծի արմատից՝

```sh
node --input-type=module --check < src/main.js
node --input-type=module --check < src/components/math-grid/math-grid.js
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo test --manifest-path src-tauri/Cargo.toml
```

Ձեռքով ստուգման դեպքերը և արդյունքների գրանցման ձևը՝ [TEST_PLAN.md](./TEST_PLAN.md)-ում։

## Ռելիզի հրապարակում

Ռելիզի օգնական սկրիպտը աշխատում է Python 3.8 կամ ավելի նոր տարբերակով՝ առանց venv-ի և արտաքին Python փաթեթների։ Պետք է նաև, որ Git-ը, Node.js-ը և Rust/Cargo-ն հասանելի լինեն `PATH`-ում, իսկ Tauri-ի build prerequisites-ը տեղադրված լինեն։

Windows-ում գործարկեք՝

```powershell
py -3 tools\release.py 0.3.0
```

Linux-ում կամ macOS-ում գործարկեք՝

```sh
python3 tools/release.py 0.3.0
```

Սկրիպտը թարմացնում է տարբերակի համարները, գործարկում ստուգումներն ու release build-ը, ապա commit և push է անում branch-ն ու `v0.3.0` tag-ը։ Հաջող tag push-ը գործարկում է Windows installer-ի GitHub Actions workflow-ը։ Այն ինքնաշխատ commit/push/tag չի անում, եթե ստուգումներից որևէ մեկը ձախողվի, աշխատանքային ծառը մաքուր չէ, կամ branch-ը `origin`-ի հետ համաժամեցված չէ։

## Տվյալների ձևաչափ

`.pdw` ֆայլերը ZIP արխիվներ են․ դրանցում տետրի տվյալները պահվում են `workbook.json`-ում, իսկ պատկերները՝ առանձին ֆայլերով։ Տվյալների կառուցվածքը նկարագրված է [workbook.schema.json](./workbook.schema.json)-ում։

Անվտանգության սահմաններ՝

- Ամբողջ `.pdw` ֆայլը՝ առավելագույնը 50 MiB, ապասեղմված տվյալները՝ 50 MiB։
- `workbook.json`-ը՝ առավելագույնը 2 MiB։
- Պատկերները՝ միայն PNG կամ JPEG, յուրաքանչյուրը՝ առավելագույնը 5 MiB, ընդհանուրը՝ 40 MiB և 100 պատկեր, ընդհանուր պիքսելները՝ 50 MP։
- Վանդակավոր դաշտը՝ առավելագույնը 200×200։
- Արխիվում թույլատրվում են միայն `workbook.json`-ը և `images/` պանակի PNG/JPEG ֆայլերը։
- Դասատուի հավաստագիրը՝ առավելագույնը 16 KiB, ստուգվում է Ed25519 ստորագրությամբ Rust backend-ում։ Ընդունվում են միայն `version: 1`, `role: "teacher"` և `issuer_id: "pensum-pilot"` արժեքները, առանց ժամկետի այս փորձնական փուլում։
- Webview-ը պաշտպանված է Content Security Policy-ով, իսկ հավելվածին տրված են միայն անհրաժեշտ Tauri թույլտվությունները։
- Պահպանումը կատարվում է ժամանակավոր ֆայլում, վերստուգվում է որպես վավեր արխիվ և միայն այնուհետև ատոմային կերպով փոխարինում է նպատակային ֆայլը, որպեսզի ձախողման դեպքում հին տետրը մնա անփոփոխ։

Windows-ում ծրագիրը տեղադրելուց հետո `.pdw` ֆայլին կրկնակի սեղմելով այն կբացվի հավելվածում։ Եթե հավելվածն արդեն բաց է, ընտրված տետրը կբացվի գործող պատուհանում։

## Սահմանափակումներ

- Փոփոխություններն ինքնաշխատ չեն պահպանվում․ դրանք պահելու համար օգտագործեք «Տետր → Պահպանել»։
- Նույն ֆայլում պահվում է միայն այն տետրը, որ ստեղծել է ընթացիկ օգտվողը։ Ուրիշի տետրը (օր․ ուսուցչի տետրը սովորողի կողմից կամ սովորողի լուծումը ուսուցչի կողմից) պահվում է նոր ֆայլով։
- Չպահված փոփոխություններով պատուհանը փակելիս ծրագիրը հարցնում է հաստատում։
- Չպահպանված փոփոխություններով տետր փակելիս կամ փոխելիս հավելվածը հաստատում է խնդրում։
- Փորձնական փուլում հավաստագիրը հեռացնելու, չեղարկելու կամ դասատուից սովորողի ձեռքով հետադարձելու UI չկա։ Դասատուի պրոֆիլը լրացվում է հավաստագիրը ներմուծելուց հետո՝ կարգավորումներում։
