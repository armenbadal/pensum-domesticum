# Փորձնական դասատուի սերտիֆիկատի պատրաստում

Այս փաստաթուղթը maintainer-ի մեկանգամյա offline գործողության հրահանգն է՝ `pensum-pilot` անվանված Ed25519 բանալու զույգը և փորձնական դասատուի `.pdcert` սերտիֆիկատը ստեղծելու համար։

Այն դպրոցի ապագա սերտիֆիկատների գեներատորը չէ և չի ներառվում installer-ում կամ release artifact-ում։

## Կարևոր նախապայման

Ներկա վիճակում `src-tauri/src/certificate.rs`-ի `PILOT_PUBLIC_KEY` արժեքը `None` է։ Դա միտումնավոր placeholder է․ քանի դեռ այն չի փոխարինվել իրական հանրային բանալիով, հավելվածը կաշխատի միայն սովորողի ռեժիմով, և ոչ մի `.pdcert` չի ընդունվի։ Մի՛ հրապարակիր release, որը պետք է աջակցի դասատուի ռեժիմին, մինչև այս քայլը կատարված չէ։

## Բանալու և սերտիֆիկատի ստեղծումը

1. Ընտրիր պահոցից դուրս գտնվող անվտանգ պանակ, օրինակ՝ `~/pensum-maintainer` կամ կրիչի գաղտնագրված հատված։ Գործիքը միտումնավոր հրաժարվում է գաղտնի բանալին գրել նախագծի պահոցում։
2. Համոզվիր, որ Python 3-ը և `cryptography` փաթեթը հասանելի են։ Անհրաժեշտության դեպքում տեղադրիր փաթեթը՝

   ```sh
   python3 -m pip install cryptography
   ```

3. Նախագծի արմատից գործարկիր՝

   ```sh
   python3 tools/pilot_certificate.py \
     --secret-out "$HOME/pensum-maintainer/pensum-pilot.key" \
     --cert-out "$HOME/pensum-maintainer/pensum-pilot.pdcert"
   ```

4. Գործիքը OS-ի անվտանգ պատահական աղբյուրով ստեղծում է 32-բայթ գաղտնի բանալի, գրում է այն `0600` թույլտվությամբ (Unix-ում), ստեղծում է `.pdcert` ֆայլը և տպում է հանրային բանալու hex ներկայացումն ու Rust-ի պատրաստի կոդի հատվածը։
5. `src-tauri/src/certificate.rs`-ում փոխարինիր՝

   ```rust
   pub(crate) const PILOT_PUBLIC_KEY: Option<[u8; 32]> = None;
   ```

   տողը գործիքի տպած `Some([...])` արժեքով։
6. Կրկին գործարկիր ստուգումներն ու release build-ը։

Գաղտնի բանալին երբեք չպետք է հայտնվի պահոցում, installer-ում, release asset-ում կամ հրապարակային հաղորդագրության մեջ։ Պահիր դրա պահուստային պատճենը նույն անվտանգ եղանակով։ Եթե բանալին արտահոսել է, ստեղծիր նոր բանալու զույգ և նոր `.pdcert`, փոխարինիր հանրային բանալին և վերահրապարակիր հավելվածը։

## Սերտիֆիկատի տրամադրումը փորձարկող դասատուներին

Փորձնական փուլում բոլոր փորձարկող դասատուները ստանում են նույն `pensum-pilot.pdcert` ֆայլը։ Այն անհատական `teacher_id` չի պարունակում․ դասատուի անունն ու էլ․ փոստը լրացվում են հավելվածի կարգավորումներում։

Ուղարկիր `.pdcert` ֆայլը դպրոցի հաստատած անվտանգ եղանակով։ Դասատուն այն ներմուծում է հավելվածի **Տետր → Սերտիֆիկատ…** կետով։ Հաջող ներմուծումից հետո հավելվածն անցնում է դասատուի ռեժիմի և բացում է կարգավորումները։

Սերտիֆիկատը պահվում է հավելվածի config պանակում՝ `teacher.pdcert` անունով։ Այն չի պահվում `localStorage`-ում և չի կարող փոխարինվել frontend-ից։

## Ստուգման հոսքը

1. Backend-ը կարդում է սերտիֆիկատի ֆայլը և ստուգում 16 KiB սահմանը։
2. JSON envelope-ից ապակոդավորում է `payload`-ի և `signature`-ի base64 արժեքները։
3. Ed25519 ստորագրությունը ստուգում է `payload`-ի սկզբնական ճշգրիտ բայթերի նկատմամբ՝ մինչև payload-ի JSON deserialization-ը։
4. Միայն հաջող ստորագրությունից հետո payload-ը deserialize-վում է խիստ typed struct-ով և ստուգվում են `version == 1`, `role == "teacher"` և `issuer_id == "pensum-pilot"` արժեքները։
5. Սերտիֆիկատը պահվում է ժամանակավոր ֆայլում և միայն հաջող վավերացումից հետո ատոմային կերպով տեղադրվում է վերջնական ուղում։

Test-երը օգտագործում են առանձին, կոդում ամրագրված test keypair և երբեք չեն օգտագործում production pilot բանալին։

## Փորձնական վերադարձ սովորողի ռեժիմին

Ներմուծված սերտիֆիկատը ջնջելու համար փակիր հավելվածը և նախագծի արմատից գործարկիր՝

```sh
python3 tools/reset_teacher_certificate.py
```

Սկրիպտը գտնում է հավելվածի config պանակը, ջնջում է `teacher.pdcert`-ը և տպում է արդյունքը։ Ապա նորից բացիր հավելվածը․ այն կաշխատի սովորողի ռեժիմով։

Օգտակար տարբերակներ՝

```sh
python3 tools/reset_teacher_certificate.py --dry-run
python3 tools/reset_teacher_certificate.py --file /custom/path/teacher.pdcert
```

Սա միայն փորձարկման եղանակ է, ոչ թե օգտվողի համար նախատեսված սերտիֆիկատի չեղարկման համակարգ։ Սկրիպտը աշխատում է Python 3-ով և չի պահանջում արտաքին փաթեթներ։
