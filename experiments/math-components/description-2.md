# Նկարագրություն ու պանահջներ

Սա դասատուի էջն է, որով նա աշակերտների համար առաջադրանքներ է սաահմանելու։ Առայժմ կան երկու տեսակի առաջադրանքներ տեքստային, որին կարելի է նաև նկար կցել ու թվաբանական, որը սահամանվում է math-grid-ով։ Դասատուն մենյուից ավելացնում է կաղապարը, գրում է առաջադրանքը ու հրապարակում է։
