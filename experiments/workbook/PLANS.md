# pensum domesticum

Desktop ծրագիրը աշխատում է երկու ռեժիմում։ I. դասատուի տարբերակը 
հնարավորություն է տալիս միայն սահմանել առաջադրանքներ։ II. աշակերտի
տարբերակը՝ միայն ավելացնել լուծումներ։ 

Առաջադրանքի ֆայլը ZIP է, որը պարունակում է JSON տեքստն ու նկարները։

Դասատուի տարբերակը հնարավորություն ունի առաջադրանքն e-mail-ով ուղարկել
աշակերտների խմբին։

Աշակերտի ծրագիրը չի կարող նոր տետր ստեղծել։ Այն հնարավորություն ունի 
միայն ավելացնե լուծումներն ու կատարված աշխատանքը հետ ուղարկել այն իրեն 
ուղարկած դասատուին։

Ծրագիրն իրականացված է Tauri+TypeScript։
