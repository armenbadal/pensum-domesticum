# Նկարագրություն ու պահանջներ

Պետք է HTML էջին լռելյայն ցույց տալ 10 տողով ու 20 սյունով աղյուսակ,
ոճավորված որպես վանդակավոր տետրի էջ։ Վանդակի կողը՝ 6 մմ։ Օգտագործողը
կարող է ավելացնել կամ հեռացնել տողեր ու սյուներ՝ պահպանելով առնվազն
մեկ տող և մեկ սյուն։ Այն
պետք է ծառայի որպես custom input: Պետք է (ցանկալի է) օգտագործել
Web Components և ElementInternals API: Օգտագործողը լրացնում է 
վանդակները։ Թույլատրելի են թվանշաններն ու մաթեմատիկական 
գործողությունների նշանները։ Այդ կոմպոնենտը պետք է օգտագործելի
լինի `<form>` թեգի մեջ ու `submit` գործողությամբ լրացված 
տվյալները պետք է ուղարկվեն։ Ցանցի չափերը, լրացված վանդակներն ու հաստացված եզրագծերը պետք է ներառվեն
form-ի արժեքում, որպեսզի ցանցը հնարավոր լինի միարժեք վերականգնել։
